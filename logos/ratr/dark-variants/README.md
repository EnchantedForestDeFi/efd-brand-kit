# RATR Mark — Dark Rope-Framed Variant

The RATR squirrel-with-scroll messenger on a **deep forest-green field**, enclosed by an ornate **rope + oak-leaf Celtic-corner frame**. This is the dark-background companion to the canonical parchment mark in [`../`](../): same messenger subject, dark treatment.

Reach for it wherever the light parchment mark would wash out — dark social embeds, dark Discord, dark website headers — and anywhere a self-contained dark tile / app-icon reads better than a transparent mark. It is the mark carried on the RATR web wallet.

The two marks are a matched pair: the **parchment** mark for light surfaces, this **dark rope-framed** mark for dark surfaces.
